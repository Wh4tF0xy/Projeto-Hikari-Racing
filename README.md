# Projeto | Hikari Racing - Discord

⚠️ **Projeto em desenvolvimento** ⚠️

O Hikari Racing é um bot de Discord desenvolvido para facilitar o uso e o gerenciamento de músicas em servidores FiveM, permitindo que os jogadores utilizem músicas dentro do jogo por meio de links compatíveis.

## 🎵 Funcionalidades

- **Conversão de links:** recebe links de músicas provenientes de diferentes plataformas e os converte para um formato compatível com a reprodução no FiveM.
- **Armazenamento de músicas:** mantém um registro das músicas enviadas ao bot, facilitando o acesso posterior.
- **Integração com Discord:** utiliza comandos e interações no Discord para facilitar o gerenciamento das músicas.

## ⚠️ Uso do Bot

- O bot deve ser utilizado apenas em servidores Discord nos quais tenha sido autorizado.
- Os links e arquivos de áudio devem ser utilizados respeitando os termos de serviço das plataformas de origem e os direitos autorais aplicáveis.
- A reprodução dentro do FiveM depende da compatibilidade do link gerado com o sistema de áudio utilizado pelo servidor.

## 🚫 Restrições

- É proibido utilizar o bot para atividades ilegais, spam, assédio ou ações que violem as Diretrizes da Comunidade do Discord.
- Não é permitido explorar, modificar ou abusar do funcionamento interno do bot sem autorização do criador.
- O uso pode ser limitado ou revogado pelos administradores do servidor.

## ⚠️ Limitação de Responsabilidade

- O criador não se responsabiliza por indisponibilidade de plataformas externas, links inválidos ou falhas na reprodução de músicas.
- O funcionamento pode variar conforme as mudanças nas plataformas de origem e nos recursos utilizados pelo servidor FiveM.
- O usuário é responsável por utilizar o conteúdo musical de acordo com as regras aplicáveis.

## 🔒 Privacidade

- O bot pode processar IDs de usuários, links enviados e informações de canais necessárias ao seu funcionamento.
- Os links de músicas são armazenados para possibilitar o gerenciamento e a reutilização da biblioteca musical.
- Os dados efetivamente armazenados e seu período de retenção dependem da implementação e da configuração do projeto.

## 🛠️ Tecnologias Utilizadas

- Python
- Discord API
- Bibliotecas e serviços de processamento de links e áudio, conforme a implementação do projeto.

## 📌 Observações

Este projeto é voltado à integração entre Discord e servidores FiveM, com foco na praticidade e na organização de músicas para uso dentro do jogo.
